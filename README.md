
# Dwak3andi-health-platforme
Application Web et Mobile pour la recherche de médicaments et la prise de rendez-vous médicaux en temps réel. Développée avec FastAPI &amp; React.

# 💊 Dwak3andi — دواك عندي
### *Plateforme Santé & Réseau Pharmaceutique en Temps Réel en Mauritanie*




## 🌟 À Propos du Projet

**Dwak3andi** (*دواك عندي* — « Votre médicament est chez nous ») est une solution numérique complète conçue pour fluidifier l'accès aux soins de santé et aux médicaments en Mauritanie.

Face aux ruptures de stock fréquentes et aux déplacements multiples nécessaires pour trouver un traitement, **Dwak3andi** connecte en temps réel les **patients**, les **pharmacies**, les **médecins**, les **cliniques** et une équipe de **modération** au sein d'un écosystème réactif, sécurisé et multilingue (Français et Arabe avec support RTL).

## 💻 Stack Technologique

### Frontend
- React 18
- Vite
- Tailwind CSS
- WebSockets
- React-i18next (Français / Arabe)
- PWA

### Backend
- FastAPI (Python)
- Uvicorn
- Pydantic
- JWT & bcrypt
- Système OTP
- Firebase Cloud Messaging
- API SMS

### Base de données & Stockage
- PostgreSQL / Supabase
- Row Level Security (RLS)
- Supabase Storage

### DevOps & Déploiement
- Docker
- Docker Compose
- Architecture multi-stage
